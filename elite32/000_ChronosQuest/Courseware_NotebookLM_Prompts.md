### 🎙️ NotebookLM 指導指令 (Focus Prompts for Synthesis)

#### 指令 1：生成教學影片摘要 (The Instructional Hook)
> "請分析上傳的《重構藍圖》與原始碼，生成一段 2 分鐘的影片開場腳本。
> 1. **破冰 (The Hook)**：提出一個問題：'你是否曾想過，只需 5 個正確的提問，就能從無到有構建一座功能完備的 3A 級互動式遊戲皇殿？'
> 2. **展示核心**：介紹 Google Antigravity 作為『時空工坊』與 Gemini『AI 指指揮官』是如何透過 UTT-v2.0 的五次元邏輯門協作的。
> 3. **語氣要求**：專業、充滿遠見、富有啟發性。"

#### 指令 2：拆解五大邏輯門的技術亮點 (The 5 Pillars)
> "請將影片的主幹分為五個教學章節，並為每個章節提煉核心金句與技術重點：
> *   **第一章：架構與視覺** - 強調 CSS 變數主題化與毛玻璃 (Glassmorphism) 的設計美學。
> *   **第二章：純動能物理** - 解釋如何利用 Ada 的運動學演算法，讓碰撞偵測變得絲滑且精確。
> *   **第三章：零資產音訊工程** - 深入探討 Web Audio API 是如何模擬出『吉卜力風格』的和弦動感。
> *   **第四章：四季與 Boss 動態** - 特別介紹『四季更迭 (bg_spring to bg_winter)』與『Boss 狂暴狀態』的數據觸發機制。
> *   **第五章：一鍵雲端部署** - 說明如何從本地開發快速推送到 GitHub Pages 的無縫流程。"

#### 指令 3：深度對話腳本 (Deep Dive: AI-Human Synergy)
> "請生成一段 NotebookLM『Audio Overview』風格的對話草稿，模擬兩位資深軟體架構師討論：

> *   情感連結：分享看到『春天綠意轉變為凜冬雪景』時的視覺成就感。"

#### 指令 4：視覺化呈現與 B-Roll 建議 (Visual Storytelling)

> 4. **標註要求**：指明每一處視覺背後對應的 UTT-v2.0 代碼原則。"
