<h2 id="繁體中文">🇹🇼 繁體中文</h2>

歡迎來到 **Stellark AI x Life Studio (星月工作室)** 的官方數位作品集。
這裡是 Master-Grade 頂級數位美學與前沿 AI 技術交會的所在。

🔗 **[點此瀏覽官方網站 (Live Website)](https://stellark-ai-studio.netlify.app/)**

### ✨ 關於工作室

Stellark Studio 致力於將複雜的 AI 概念與數位工程，轉化為沉浸式、視覺震撼且具備高度教育價值的體驗。我們的核心專長包含：
- **頂級 UI/UX 設計 (Master-Grade)**：精通現代網頁標準，如玻璃擬態 (Glassmorphism)、CSS 微動畫與流暢排版。
- **AI 整合與創作**：搭建人類創意與生成式 AI 工具（如 Gemini, Veo）之間的橋樑。
- **數位教育與工程**：透過 Python 自動化與數據分析教學，賦能學習者。

### 🚀 精選專案

- **八角旋律 (Octagonal Melody)**：互動式視覺合成器，結合網頁音效與動畫。
- **機械時光 (Mechanical Watch)**：極致精密的 CSS/JS 互動工程模擬。
- *更多詳細專案請直接前往我們的官方網站探索。*

### 🛠️ 技術堆疊

本作品集以追求極致效能為目標，採用無依賴的現代原生網頁技術打造：
- 語意化 **HTML5**
- 現代化 **CSS3** (原生變數、Grid/Flexbox、微動畫)
- 原生 **JavaScript** (ES6+)
- 透過 **GitHub & Netlify** 實現全自動 CI/CD 部署

### ✨ About the Studio

Stellark Studio is dedicated to transforming complex AI concepts and digital engineering into immersive, visually stunning, and highly educational experiences. We specialize in:
- **Master-Grade UI/UX Design**: Leveraging modern web standards like Glassmorphism, CSS micro-animations, and fluid typography.
- **AI Integration**: Bridging the gap between human creativity and Generative AI tools.
- **Digital Education & Engineering**: Empowering learners with Python automation and data analytics skills.

### 🚀 Key Projects

- **Octagonal Melody (八角旋律)**: An interactive visual synthesizer.
- **Mechanical Watch (機械時光)**: Precision CSS/JS engineering simulation.
- *Explore more detailed projects directly on our live website.*

### 🛠️ Technology Stack

This portfolio is built with a focus on high performance and zero-dependency native web standards:
- Semantic **HTML5**
- Modern **CSS3** (Native Variables, Grid/Flexbox, Micro-animations)
- Vanilla **JavaScript** (ES6+)
- Automated CI/CD Pipeline via **GitHub & Netlify**
